MACK DMS — Manual & Info Sharing

Purpose
Manual & Info Sharing is the umbrella area for DMS modules that share manuals, bulletins, and controlled information widgets with shore and ship users.

Typical modules under / related to this area
- Manuals and information documents
- Bulletins / bulletin view
- DMS module entries configured in Profile Access Management (PAM) / User Level Security (ULS)
- Widgets such as recent documents / info-sharing widgets on dashboards

How to use as a reader
1. Open Manual & Info Sharing
2. Select the relevant module (manuals, bulletin, etc.)
3. Search or browse
4. Open Quick View if available
5. Download only if your role and process allow it
6. Confirm you are reading the current revision

How to use as a publisher / controller
1. Place the document in the correct module and folder
2. Attach the controlled file (PDF/HTML/other allowed type)
3. Set audience / distribution
4. Publish
5. Verify widget counts and recent lists if your company uses dashboard widgets
6. Communicate the change to affected users if required by SMS procedure

Access checks
If a user can see a DMS entry in PAM/ULS configuration but cannot open it in the module search:
- Confirm module mapping and profile rights
- Confirm the module is enabled for that user’s role
- Confirm environment (prod vs test) and company scope
- Collect screenshots of PAM entry and the user search result for support

Widget sanity checks
- Recent document counts should match expectation after publish
- If counts look wrong, refresh, re-login, then raise support with company, module, and timestamp
