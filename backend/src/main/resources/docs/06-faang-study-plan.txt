Vicky Assist FAANG Training — 8-Week Study Plan

Goal
Reach interview-ready performance for FAANG-style coding, design, and behavioral rounds.

Week 1 — Foundations
- Arrays, strings, hashing
- Complexity fluency
- 10 easy + 5 medium problems
- Build STAR story outline list

Week 2 — Pointers and windows
- Two pointers, sliding window
- Prefix sums
- 12 medium problems
- Mock phone screen (45 min)

Week 3 — Trees and recursion
- Binary trees, BST, recursion stack thinking
- BFS/DFS mastery
- 10 medium tree problems

Week 4 — Graphs
- BFS/DFS graphs, topological sort, union-find intro
- 8–10 graph mediums
- Start system design notes: URL shortener + rate limiter

Week 5 — Heaps, intervals, binary search
- Top-K, merge intervals, search-on-answer
- 10 mixed mediums
- Design: news feed + chat high level

Week 6 — Dynamic programming
- 1D DP then 2D DP
- Coin change, LIS, knapsack family, edit distance
- One hard DP with strong approach notes

Week 7 — Full mocks
- 3 timed coding mocks
- 2 system design mocks
- 1 behavioral mock
- Review weak patterns only

Week 8 — Polish and company targeting
- Re-solve previously failed problems from memory
- Company-specific behavioral mapping (Amazon LPs, Google Googliness themes)
- Sleep, logistics, and offer negotiation basics

Daily routine (2–3 hours)
1. 15 min review yesterday mistakes
2. 60–90 min new problem(s) with timer
3. 20 min rewrite clean solution
4. 20–30 min design or behavioral alternate days

Offer / negotiation basics
- Get level and location clear
- Compare total comp: base + bonus + equity
- Ask for time to decide; avoid ultimatums
- Competing offers help; honesty matters

Definition of ready
- Can solve most mediums in ~30–35 minutes with explanation
- Can run a structured design conversation without freezing
- Can tell 8 STAR stories cleanly
- Can recover from stuck moments with interviewer collaboration
