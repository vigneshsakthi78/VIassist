MACK DMS — Getting started

Typical navigation
1. Log in to MACK / NiBiKi with your company credentials
2. Open Manual & Info Sharing (or the DMS entry configured for your profile)
3. Choose the module you need, for example:
   - SMS & Circulars
   - Manuals / controlled manuals
   - Bulletins
   - Forms / checklists (where enabled)
4. Use search or folder tree to locate the document
5. Open Quick View or download/view according to your role and permissions

Before you start work
- Confirm you are in the correct company / fleet / environment
- Confirm your role can view or edit the target module (PAM / User Level Security)
- Prefer searching by Document ID when you have it (example pattern: DMSDOC#####)
- Prefer folder path when browsing (example: SMS → SMS-Ship → Chapter …)

Document identity basics
- Document ID: stable reference used in support and audits
- Title / subject: human-readable name
- Folder / category path: where the document lives in the hierarchy
- Version / revision: which controlled issue is current
- Distribution: which vessels or offices should receive it

Good daily habits
- Always open the latest controlled version, not a personal copy from email
- After office publishes a change, confirm vessel sync/receipt if your process requires it
- Do not overwrite controlled content outside the approved DMS edit flow
