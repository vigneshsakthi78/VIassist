MACK DMS — Getting started

Source: ONESEA/KLNG DMS Admin Training (SharePoint DMS Training Material)

Login
1. Use Chrome browser
2. Open your company MACK URL (example pattern used in training: https://<customer>.macksvm.com/)
3. Sign in with provided username and password
4. If your account has multiple roles, use Switch Profile instead of logging in again

MACK layout items users commonly use
- Download Manager
- Chat / Alerts / Notifications / Tasks
- Language toggle, fullscreen, minimize module menu
- Quick Access / Management / Resources
- Personalization (images)
- Calendar, clocks, news/events on home page

Open DMS
1. From MACK modules, open DMS
2. Use the folder tree on the left to browse
3. Use Search or Advanced Search to find by title, content/page, or Document ID
4. Open a document to use the right-side utility bar

Daily reader habits
- Prefer latest published controlled document in DMS over email copies
- Add frequently used manuals to Favourites
- Use Quick Navigate inside long documents
- Check Bell notifications for workflow / published items relevant to you
