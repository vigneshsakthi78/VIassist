Lesson 1: How to think in array interviews
Step 1: Restate input/output with one example
Step 2: Ask constraints (n size, negatives, duplicates, sorted?)
Step 3: Give brute force
Step 4: Find bottleneck
Step 5: Apply pattern (hashing / two pointers / prefix / window)
Step 6: State complexity and edge cases

Lesson 2: Prefix sum
Use when you need many range sums quickly.
Build prefix where prefix[i] = sum of first i elements.
Range i..j becomes prefix[j]-prefix[i-1].
Interview tip: combine prefix with hashmap for subarray sum equals K.

Lesson 3: Sliding window teaching script
"I will maintain a window [left,right].
I expand right to include new elements.
If the window becomes invalid, I shrink left until valid.
I update the answer whenever the window is valid."
Use for longest/shortest contiguous subarray/substring with a constraint.

Fixed window vs variable window
- Fixed: size always k (max sum of k elements)
- Variable: size grows/shrinks based on condition

Lesson 4: Binary search teaching script
"I will binary search over a monotonic search space.
I define a predicate isOK(mid).
If true, I search for a better answer on one side; else the other side."
Classic index search and binary search on answer are both required.

Common mistakes to correct
- Starting code before clarifying constraints
- Using O(n^2) when n is 1e5
- Off-by-one in window and binary search bounds
- Forgetting empty/single-element edge cases
