Vicky Assist Teaching Guide — Take U Forward A2Z Roadmap

Source sheet (practice here):
https://takeuforward.org/strivers-a2z-dsa-course/strivers-a2z-dsa-course-sheet-2/

Public sheet goal
Learn DSA from A to Z in a structured way for FAANG and product-based companies.
The sheet contains hundreds of problems across Easy/Medium/Hard.

Module map and what to ask Vicky Assist

1) Learn the basics
Ask: "Teach Java basics needed for interviews"
Then solve Basics module on Take U Forward.

2) Sorting
Ask: "Teach merge sort vs quick sort for interviews"
Practice sorting module problems on TUF.

3) Arrays Easy -> Medium -> Hard
Ask: "Teach prefix sum and kadane interview pattern"
Practice Arrays module thoroughly. This is the foundation.

4) Binary Search
Ask: "Teach binary search on answer with examples"
Practice 1D/2D/search-space problems on TUF.

5) Strings
Ask: "Teach anagram and substring patterns"
Practice TUF Strings module.

6) Linked List
Ask: "Teach reverse linked list and cycle detection"
Practice Singly/Doubly/Medium/Hard LL on TUF.

7) Recursion pattern-wise
Ask: "Teach subset and combination recursion templates"
Practice recursion module on TUF.

8) Bit Manipulation
Ask: "Teach XOR interview tricks"
Practice bit module on TUF.

9) Stack and Queues
Ask: "Teach monotonic stack and next greater element"
Practice stack/queue module on TUF.

10) Sliding Window and Two Pointers
Ask: "Teach variable sliding window step by step"
Practice combined window/pointer problems on TUF.

11) Heaps
Ask: "Teach top-K heap pattern"
Practice heaps module on TUF.

12) Greedy
Ask: "Teach activity selection and jump game thinking"
Practice greedy module on TUF.

13) Binary Trees
Ask: "Teach DFS return-value pattern for trees"
Practice traversals + medium/hard trees on TUF.

14) Binary Search Trees
Ask: "Teach validate BST and kth smallest"
Practice BST module on TUF.

15) Graphs
Ask: "Teach BFS DFS topo sort for interviews"
Practice graphs module on TUF. Critical for FAANG.

16) Dynamic Programming
Ask: "Teach DP from recursion to tabulation"
Practice DP patterns/problems on TUF. Highest leverage.

17) Tries
Ask: "Teach trie insert search startsWith"
Practice tries module on TUF.

18) Advanced Strings
Ask: "Teach KMP intuition at interview level"
Practice advanced string problems on TUF.

Progress rule used by Vicky Assist
Do not jump to DP/Graphs until Arrays + Binary Search + Sliding Window are comfortable.
If stuck on a problem more than 25-30 minutes, ask Vicky Assist for approach hints, then retry on TUF.
