Vicky Assist FAANG Training — Binary Search, Sliding Window, Stack/Queue (A2Z aligned)

Binary Search
Use when search space is monotonic.
Forms:
1. Classic search in sorted array
2. Lower bound / upper bound
3. Search in rotated sorted array
4. Binary search on answer (capacity, speed, aggressiveness)

Binary search template tips
- Decide inclusive bounds carefully
- Define mid safely
- Write a predicate isOK(mid)
- Prove monotonicity before coding
- Complexity O(log n) over answer/index space

Sliding Window + Two Pointers
Use for subarray/substring constraints.
Fixed window: maintain sum/count for size k
Variable window: expand right, shrink left while invalid
Examples:
- Longest substring without repeating characters
- Max consecutive ones with at most K flips
- Minimum window substring (advanced)
- Pair sum in sorted array

Stack and Queue
Stack uses:
- Valid parentheses
- Next greater/smaller element (monotonic stack)
- Histogram largest rectangle
- Min stack
Queue / Deque uses:
- BFS
- Sliding window maximum with deque
Expression conversion:
- Infix / prefix / postfix basics

Interview cues
- "Next greater" => monotonic stack
- "Longest subarray with constraint" => sliding window
- "Minimize maximum" / "maximize minimum" => binary search on answer

Practice focus
- 10 binary search problems including answer-space
- 8 sliding window mediums
- 8 monotonic stack / parentheses problems

Communication tip
Before coding window problems, clearly state what the window represents and the invariant that makes shrink/expand correct.
