Lesson 1: Tree recursion pattern
Most tree mediums need a function that returns useful values (height, gain, validity),
not only visits nodes.
Template:
- handle null base case
- recurse left/right
- combine results for current node
- return value to parent

Must-know tree talks in interviews
- Traversals and when to use BFS vs DFS
- Diameter / max path concepts
- LCA
- Validate BST
- Level order zigzag

Lesson 2: Graph interview framework
First ask:
- Directed or undirected?
- Weighted or unweighted?
- Can there be cycles?
Then choose:
- BFS for shortest path in unweighted graphs
- DFS for components/cycle exploration
- Topological sort for dependency order
- Dijkstra for non-negative weighted shortest path
- Union-Find for connectivity queries

Teaching script for graphs
"I will build an adjacency list.
Then I will traverse with BFS/DFS while tracking visited state.
For directed cycle detection I need recursion stack or colors.
For topo sort I can use Kahn indegrees."

Lesson 3: DP teaching ladder
Never jump to tabulation blindly.
1. Write brute-force recursion
2. Identify overlapping subproblems
3. Add memoization
4. Convert to bottom-up DP
5. Optimize space if possible

DP state questions to ask yourself
- What is the index/state?
- What decision do I make at this state?
- What is the base case?
- What is the final answer state?
