Vicky Assist FAANG Training — Linked List, Recursion, Bit Manipulation (A2Z aligned)

Linked List essentials
- Reverse iterative and recursive
- Detect cycle (Floyd) and find cycle start
- Find middle (fast/slow)
- Merge two sorted lists
- Remove Nth from end
- Intersection of two lists
- Flatten / reorder list style problems
- LRU Cache often combines hashmap + doubly linked list

Linked list interview tips
- Draw pointers
- Use dummy head to simplify edge cases
- Update next carefully to avoid losing nodes
- Talk through one example before coding

Recursion pattern-wise
- Parameterized vs functional recursion
- Subsequences / subsets
- Combination sum
- Permutations
- N-Queens style backtracking
- Merge sort / tree recursion as recursion practice

Recursion checklist
1. Base case
2. State changing toward base
3. Avoid infinite recursion
4. Estimate recursion stack space
5. Convert to iterative/DP when overlapping subproblems appear

Bit manipulation concepts
- AND OR XOR NOT, shifts
- Check/set/unset/toggle bit
- Count set bits
- XOR tricks: missing number, single number
- Power of two checks
- Bitmask DP intro (advanced)

When bits help in interviews
- Compact state representation
- XOR pairing problems
- Fast parity / subset enumeration for small n

Common FAANG follow-ups
- Can you reverse list in groups of K?
- Can you do recursion with O(1) extra memory?
- Can you solve using XOR in O(1) space?
