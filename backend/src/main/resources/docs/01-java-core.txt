Vicky Assist FAANG Training — Interview Process and Rounds

Typical FAANG / top-tech loop
1. Recruiter screen (role fit, timeline, compensation band overview)
2. Online assessment or phone screen (coding)
3. Onsite / virtual onsite loop (4–6 rounds)
4. Hiring committee / debrief
5. Offer and leveling discussion

Common onsite round mix
- 2 coding rounds (algorithms + data structures)
- 1 system design round (mid/senior+; sometimes lighter for junior)
- 1 behavioral / leadership round
- Sometimes: domain round (mobile, frontend, ML, distributed systems)

What interviewers evaluate
- Problem solving and pattern recognition
- Code quality and correctness under time pressure
- Communication and structured thinking
- Ability to handle hints and course-correct
- For senior: architecture judgment, trade-offs, mentorship signals

Leveling signals (simplified)
- L3/L4 / SDE1: solid coding, clean fundamentals, some design intuition
- L5 / SDE2: strong coding + solid system design + ownership stories
- L6+ : complex design, cross-team impact, technical leadership

Phone screen strategy (45–60 min)
- 2–5 minutes clarifying questions
- 5 minutes approach discussion
- 25–35 minutes coding
- 5 minutes complexity + tests
- Leave 2–3 minutes for candidate questions

Communication script (coding)
1. "Here is how I understand the problem..."
2. "Constraints imply we need better than O(n^2)..."
3. "Brute force would be X; optimized approach is Y because..."
4. "I'll implement Y and then cover edge cases: empty, duplicates, negatives..."
5. "Time is O(...), space is O(...)."

Red flags to avoid
- Jumping into code with no plan
- Ignoring interviewer hints
- Silent coding for long stretches
- Not testing the solution
- Claiming O(1) incorrectly

Company flavor (high level)
- Google: strong CS fundamentals, clean algorithms, follow-ups
- Meta: practical coding speed + product sense in design
- Amazon: Leadership Principles in behavioral + coding bar
- Apple: craftsmanship, depth, sometimes domain-specific
- Netflix: senior bar, ownership, high-context communication

Prep metrics
- Coding: 3–5 quality problems/day beats 20 rushed ones
- Design: 2–3 designs/week with diagrams and trade-offs
- Behavioral: 8–12 reusable STAR stories mapped to themes
