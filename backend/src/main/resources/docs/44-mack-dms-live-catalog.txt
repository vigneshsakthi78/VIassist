Column map the coach should use when explaining storage
dmsdocumentmaster: one row per folder, HTML page, or file node. filetypeflag P folder, H HTML page, F file. docstatus is the workflow status. parent links to the parent docid. doccontent is the HTML body and is not in this training extract.
dmsfilemanager: attachments for a docid. uniquefilename is the stored name. source marks where the file came from.
dmsimagemanager and dmsvideomanager: tree of image or video assets. filetype distinguishes folder vs file. parent is the parent node docid.
dmsdocumenttype: master list of document type codes used by workflow and pages.
dmsdocstatus: status codes shown in the grid and workflow.
dmsdocumentflow: which department and document type use which workflow. Author, reviewer, and approver user lists are omitted.
dmssetting: module configuration keys. Secret and long values are omitted.
dmsvariables / dmstemplates: company variable and template masters. The stored HTML or data payloads are omitted.
