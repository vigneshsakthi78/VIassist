Vicky Assist FAANG Training — Arrays, Sorting, Hashing (A2Z aligned)

Module intent
These topics are the base of FAANG coding rounds. Master them before trees/graphs/DP.

Sorting techniques to know
- Selection / Bubble / Insertion: understand mechanics (rarely optimal)
- Merge sort: O(n log n), stable, extra space
- Quick sort: average O(n log n), worst O(n^2), partition logic
- Counting / Radix: special integer cases
- Library sort in interviews is OK after explaining complexity

Array patterns
- Prefix sums for range sums
- Kadane for maximum subarray
- Two pointers on sorted arrays
- Dutch national flag (sort 0/1/2)
- Next permutation thinking
- Merge intervals
- Rotate / reverse subarrays in-place
- Majority element (Boyer-Moore)
- Stock buy/sell one transaction

Hashing patterns
- Frequency maps
- Two Sum family
- Subarray sum equals K (prefix + hashmap)
- Longest consecutive sequence
- Group anagrams
- Count distinct in window

Interview communication for array problems
1. Ask if array is sorted, mutable, contains negatives/duplicates
2. State brute force
3. Move to O(n) / O(n log n) target based on constraints
4. Watch index boundaries and integer overflow

High-value practice set names (solve on TUF/LeetCode)
- Two Sum
- Maximum Subarray
- Merge Intervals
- Sort Colors
- Next Permutation
- Subarray Sum Equals K
- Longest Consecutive Sequence
- 3Sum
- Set Matrix Zeroes
- Spiral Matrix

Common mistakes
- Ignoring constraints (n=1e5 needs better than O(n^2))
- Mutating input unexpectedly
- Off-by-one in windows and partitions
- Not handling empty arrays
