MACK DMS — Find, view, and download documents

Find a document quickly
Option A — by Document ID (best for support and audits)
1. Open the DMS module
2. Search using Document ID (example: DMSDOC21708)
3. Open the result and confirm title/folder path

Option B — by folder path
1. Open SMS / Manuals module
2. Drill folder levels (Level 1 → Level 2 → Chapter/section)
3. Open the document from the correct leaf folder

Option C — by title keywords
1. Search key words from the document title
2. Filter by module/category if filters exist
3. Verify revision/effective information before use

View
- Prefer Quick View for fast reading when available
- If Quick View is blank:
  - Try another document in the same folder to see if it is document-specific
  - Try download/open in viewer if permitted
  - Note browser, vessel/office, Document ID, and module for support

Download / print
- Follow company policy; some controlled documents are view-only
- Do not create uncontrolled local “working copies” as the source of truth
- After download for legitimate use, destroy/replace outdated local copies per procedure

Attachment checks
- Confirm the attachment opens and matches the document title/revision
- For comparison issues (SMS & Circular reports), check whether attachment mismatch is office-side, vessel-side, or sync-related
