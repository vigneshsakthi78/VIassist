MACK DMS — Access, roles, and permissions

Access is controlled
Users only see DMS modules and actions allowed by Profile Access Management (PAM) / User Level Security (ULS) and company role mapping.

If you cannot see a module
1. Confirm you are logged into the correct company environment
2. Ask your admin whether the module is enabled for your profile
3. Compare with a colleague who has access
4. Raise an access request through the approved support/service desk process

If you can see configuration but cannot use the module
- Module may be listed under Manual & Info Sharing → DMS Modules in PAM/ULS but not searchable/usable in the application UI
- Provide admin/support with:
  - username / role
  - module name shown in PAM
  - what appears (or does not appear) in module search
  - screenshots

Least-privilege habits
- Request only the access needed for your job
- Do not share passwords or shared generic logins
- For temporary project work, request time-bound access if your process supports it

When access is not the issue
If permissions look correct but documents are missing, check distribution, folder path, Document ID, and sync before assuming an access bug.
