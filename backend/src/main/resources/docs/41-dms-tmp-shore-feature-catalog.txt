Module: ndeCBean (DMS Admin / SMS & Circulars). UI Version on DMS shell: 2.4.

What this module is
MACK DMS for SMS manuals and Circulars. Shore users browse a document tree, author HTML/PDF/folder
nodes, run workflow (draft → review → approve → publish), set visibility (company, vessel, rank,
department), attach files, and sync to vessels / external apps.

Node types
- Folder (filetypeflag P): container. Add Page / Add Folder only under a folder.
- HTML page (H): CKEditor document.
- PDF / file (F): uploaded via Document Manager / path.
- External link: URL-type node.

How to open SMS & Circulars (live)
1. Open the customer Mack shore URL (login title: DMS TMP Shore).
2. Sign in with assigned User ID / Password (LOGIN).
3. Home dashboard: shortcut SMS & Circulars, or menu Manuals & Info Sharing → DMS Modules → SMS & Circulars.
4. Confirm dialog "DMS Application will be Opened in New Tab?" then DMS opens at /DMS/main.

Add Page dialog (live labels)
Header: Add Page
Fields: Name, Type (Page), Page Template (Blank Page), Page Icon (Page), Header Template (Default Header), Footer Template (Default Footer), URL
Submit: Add Page
Create only under a folder. Double-submit is guarded in code (SDT-19428).

Page Properties (live labels)
Tabs: Document, Distribution

Applicable To (Ship / Shore / Common), Search Tags, Reference Regulation, Reason for Revision,
User Version, Page Template, Page Header, Page Footer, WaterMark*, Company, Department, Rank,
Vessel Department, Vessel Rank, Vessel Flag, Vessel Type, Region, Category, Date of Creation,
Date of Published, Date of Expiry.
Note: Either ALL or Individual values can be selected.
Distribution: Company Selection*, Vessel Type*, Vessel Flag*, Vessel* (circulars), Add Documents.
