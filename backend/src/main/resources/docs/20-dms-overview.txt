MACK DMS — Overview (from official training materials)

Source: MACK-DMS SharePoint → Documents → DMS Training Material
(Seaspan DMS Quick Guide; ONESEA/KLNG DMS Admin Training)

What is MACK DMS?
MACK DMS is Solverminds’ Document Management System for controlled maritime documents
such as SMS manuals, circulars, and related company information used by shore and ship users.

Typical landing areas in MACK
- New / Delete / Mark as Favorite / Filter
- Navigation pane (folder tree)
- Search / Advanced Search / Notifications / Download Manager / Refresh
- Side utility bar on a document (comments, attachments, favourites, page properties, download, print)
- Admin / Functional / Technical tools for masters, managers, and reports

Who does what (role summary)
- Super Admin (shore): cross-company setup, mapping, masters
- Local Admin (shore): users and functional roles within own company
- Vessel Admin / Master (ship): vessel-side admin actions
- Normal users: view and work within company / vessel scope

Core idea
Documents live in a folder tree, move through workflow (create → review → approve → publish),
and become visible to the intended shore/ship audience based on visibility, security, and sync.
