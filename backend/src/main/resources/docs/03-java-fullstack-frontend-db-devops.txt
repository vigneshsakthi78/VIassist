Vicky Assist FAANG Training — DSA Deep Dive for Interviews

Big-O interview fluency
- O(1), O(log n), O(n), O(n log n), O(n^2), O(2^n)
- Always give both time and space
- Mention average vs worst case for hash tables and quicksort

Arrays and strings
- In-place reverse, rotate, two-pointer partition
- Prefix sums for range queries
- String anagram via counts
- Kadane for max subarray

Linked lists
- Dummy head technique
- Fast/slow pointers for cycle and middle
- Reverse list iterative and recursive
- Merge two sorted lists

Trees
- DFS: preorder / inorder / postorder
- BFS level order with queue
- Validate BST
- Diameter, max path sum style recursion
- LCA in binary tree / BST

Graphs
- BFS for shortest path in unweighted graphs
- DFS for components and cycle detection
- Topological sort for DAGs
- Dijkstra for non-negative weighted shortest path
- Detect cycle in directed vs undirected carefully

Dynamic Programming ladder
1. Climbing Stairs / Fibonacci style
2. House Robber
3. Coin Change
4. Longest Increasing Subsequence
5. Unique Paths
6. Edit Distance
7. 0/1 Knapsack family
Framework: define state -> transition -> base -> order -> answer

Sliding window classics
- Fixed window max sum
- Variable window longest substring with constraint
- Minimum window substring (harder)

Binary search classics
- Lower/upper bound
- Search in rotated sorted array
- Koko eating bananas / capacity to ship packages (binary search on answer)

Heap classics
- Kth largest
- Merge k sorted lists
- Median from data stream (two heaps)

Practice grading rubric
- Optimal complexity: full score path
- Correct but suboptimal: partial
- Bugs in edge cases: major deduction
- Poor communication: soft no even with working code

Timed drill plan
- Easy warm-up: 10–15 min
- Medium: 25–35 min
- Hard: 40–45 min (focus on approach quality)
- After each problem: rewrite clean solution from memory next day
