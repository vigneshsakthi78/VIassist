Pattern cheat sheet
- Two Sum / frequency: HashMap
- Sorted pair problems: Two pointers
- Longest/shortest subarray with constraint: Sliding window
- Sorted search / monotonic predicate: Binary search
- Next greater element: Monotonic stack
- Shortest path unweighted: BFS
- Dependencies / course schedule: Topological sort
- Overlapping subproblems: DP
- Generate combinations/permutations: Backtracking
- Merge K lists / top K frequent: Heap

How to pick complexity targets
- n up to 1e5: aim O(n) or O(n log n)
- n up to 1e3: O(n^2) may pass
- Always confirm constraints before choosing approach

Universal coding template
1. Restate problem + examples
2. Clarify input sizes, duplicates, sorted?, mutability
3. Brute force
4. Bottleneck analysis
5. Optimized approach + why correct
6. Code
7. Dry-run example
8. Edge cases
9. Complexity

Java tips for interviews
- Prefer ArrayDeque over Stack class
- Use HashMap.merge / getOrDefault for frequencies
- Know Arrays.sort and Collections.sort comparators
- For graphs: List<List<Integer>> adjacency list
- Watch integer overflow; use long when needed
- Avoid premature micro-optimizations; prioritize clarity

Debugging under pressure
- Print mental walkthrough of first failing case
- Check off-by-one in binary search (low/high/mid)
- Check window shrink/expand invariants
- Null/empty checks for trees and lists
